# workflow-tools

Personal workflow utilities and reusable templates.

## Active projects

- [`extensions/chrome/chatflow`](extensions/chrome/chatflow): the ChatFlow Chrome extension.
- [`scripts/tampermonkey`](scripts/tampermonkey): existing userscripts retained during the ChatFlow migration.
- [`templates/powerpoint`](templates/powerpoint): PowerPoint templates.

Userscripts are intentionally kept unchanged while equivalent ChatFlow modules are tested. When a feature is enabled in ChatFlow, disable its Tampermonkey counterpart in the browser to avoid duplicate actions.
